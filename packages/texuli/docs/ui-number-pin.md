# NumberField and PinInput

`texuli/number-pin` styles the owned `@texuli/primitives/number-field` and
`@texuli/primitives/pin-input` controls with Texuli tokens. Both components
support `sm`, `md` and `lg` sizes and accept consumer classes.

```svelte
<script lang="ts">
  import { NumberField } from 'texuli/number-pin';
</script>

<label for="quantity">Quantity</label>
<NumberField.Root id="quantity" value={2} min={0} max={10}>
  <NumberField.Decrement />
  <NumberField.Input aria-label="Quantity" />
  <NumberField.Increment />
</NumberField.Root>
```

`NumberField.Root` and its parts preserve the primitive's locale formatting,
keyboard spinbutton behavior, bounds, optional wheel stepping and native form
submission. Set translated `incrementLabel` and `decrementLabel` on the root
when the default English labels are not appropriate.

```svelte
<script lang="ts">
  import { PinInput } from 'texuli/number-pin';
  import { REGEXP_ONLY_DIGITS } from '@texuli/primitives/pin-input';
  let code = $state('');
</script>

<label for="code">Verification code</label>
<PinInput.Root bind:value={code} inputId="code" maxlength={6} pattern={REGEXP_ONLY_DIGITS}>
  {#snippet children({ cells })}
    {#each cells as cell, index (index)}<PinInput.Cell {cell} />{/each}
  {/snippet}
</PinInput.Root>
```

`PinInput.Root` passes its extra attributes to that real input, typed as
input attributes: `name`, `form`, `required`, `autocomplete`, `aria-*`,
`data-*` and handlers (a handler you pass runs before the part's own and
never replaces it). `bind:inputRef` binds the real input element.

The pin field remains one real, labeled input for typing, paste, autofill and
assistive technology. Its cells are decorative and hidden from the accessibility
tree. `mask` renders a password input and masked cells. The registered
`texuli-number-pin` example shows every size, disabled and read-only state, RTL,
and a dark surface.

## Tokens

Set these on any element above the component (a theme scope, a design
system scope or `data-tx-scope`); each defaults to the system or theme token
shown, so nothing changes until one is set. The full list, with the exact
read expressions, is in
[tokens-components](../../tokens/docs/tokens-components.md#component-tokens).

### Number field (`number-field`)

| Token | Default | Meaning |
| --- | --- | --- |
| `--tx-number-field-radius` | `var(--tx-shape-radius-lg)` | Corner radius. |
| `--tx-number-field-border-width` | `var(--tx-border-width-thin)` | Border width. |
| `--tx-number-field-padding-block` | `var(--tx-space-2)` | Input block padding. |
| `--tx-number-field-padding-inline` | `var(--tx-space-3)` | Input inline padding. |
| `--tx-number-field-stepper-size` | `var(--tx-size-control-md)` | Stepper button minimum inline size. |

### PIN input (`pin-input`)

| Token | Default | Meaning |
| --- | --- | --- |
| `--tx-pin-input-gap` | `var(--tx-space-2)` | Gap between cells. |
| `--tx-pin-input-cell-inline-size` | `var(--tx-size-control-lg)` | Cell inline size. |
| `--tx-pin-input-cell-block-size` | `var(--tx-space-12)` | Cell block size. |

| `--tx-pin-input-cell-font-size` | `var(--tx-type-heading-size)` | Cell font size. |
