# Component messages (i18n)

> **Status: unreleased, planned for 0.8.0** (ADR-016). English is the only
> language Texuli ships; translations beyond English are planned. Hosts can
> load their own catalogs today.

**Package:** `texuli` · **Import:** `import { setI18nContext, useMessages, TEXULI_MESSAGES_EN } from 'texuli'`

Every label a styled component writes itself (close buttons, empty and
error states, navigation names, carousel and command palette text…)
resolves through the [`@texuli/core/i18n`](../../core/docs/core-i18n.md)
message catalog, in this order:

1. the **instance prop** when you set one (`closeLabel="Shut"`, or a key of
   a `labels` object): existing props keep working and always win;
2. the **catalog in context**: the active locale, then its base language;
3. the component's **English default**.

```svelte
<script lang="ts">
  import { createI18n } from '@texuli/core/i18n';
  import { setI18nContext } from 'texuli';

  const i18n = setI18nContext(
    createI18n({ locale: 'en', loaders: { 'pt-BR': () => import('./locales/pt-BR.ts') } })
  );
</script>
```

| Export | What it does |
| --- | --- |
| `setI18nContext(i18n)` | Puts one `I18n` in Svelte context for every component below (call it in a component's script); returns it. The context key is `@texuli/core/i18n`'s `I18N_CONTEXT`, so `@texuli/primitives` reads the same catalog |
| `getI18nContext()` | The `I18n` in context, or `undefined` |
| `useMessages()` | The component-side `MessageLookup` (`(id, english, values) => string`, plus `has(id)`): reactive in `$derived` and markup, so labels update when the locale or catalogs change (lazy locales included); English only when no `I18n` is in context. Call during component initialization |
| `TEXULI_MESSAGES_EN` | Every styled component label id (`texuli.<component>.<label>`, such as `texuli.dialog.close-label`) with its English default: the catalog a translation starts from. Components keep their defaults inline, so tree shaking still works; a test keeps this catalog equal to them |

Messages are always rendered as text, never markup. Function labels (such
as a tag's remove label) take their arguments as `{0}`, `{1}`… when a
catalog translates them. Without an `I18n` in context the components cost
only their inline English strings.

Tests: `packages/texuli/tests/i18n.test.ts` (catalog coverage under the
pseudo-locale, resolution order, live locale changes).
