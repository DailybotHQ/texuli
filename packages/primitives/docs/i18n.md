# Primitive messages (i18n)

> **Status: unreleased, planned for 0.8.0** (ADR-016). English is the only
> language Texuli ships; translations beyond English are planned. Hosts can
> load their own catalogs today.

**Package:** `@texuli/primitives` · **Import:** `import { setI18nContext, useMessages, PRIMITIVES_MESSAGES_EN } from '@texuli/primitives'`

The few labels a headless primitive writes itself (pagination's previous
and next buttons, a toast's close button, calendar and date-field segment
names, file drop and tags input announcements…) resolve through the
[`@texuli/core/i18n`](../../core/docs/core-i18n.md) message catalog: the
instance prop when set, then the catalog in context (the active locale,
then its base language), then the English default.

| Export | What it does |
| --- | --- |
| `setI18nContext(i18n)` | Puts one `I18n` in Svelte context for every primitive below; returns it. Same context key (`I18N_CONTEXT`) as `texuli`'s, so one call serves both packages |
| `getI18nContext()` | The `I18n` in context, or `undefined` |
| `useMessages()` | The `MessageLookup` a primitive part reads: reactive, English only without an `I18n` in context. Call during component initialization |
| `PRIMITIVES_MESSAGES_EN` | Every primitive label id (`primitives.<primitive>.<label>`, such as `primitives.pagination.next-label`) with its English default, the catalog a translation starts from; a test keeps it equal to the inline defaults |

Messages are rendered as text, never markup.

Tests: `packages/primitives/tests/i18n.test.ts`.
