## Visual builder

The in-development `@texuli/forms/builder` subpath exports `FormBuilder`. It provides a field palette, a keyboard and pointer sortable canvas, a field inspector, a live schema form preview and a schema JSON view. It was added after `0.17.4`, is not in a published release yet, and is planned for the next release.

The builder edits a flat, single-page field list. It does not preserve a multi-step or section layout when editing; use it to author a flat schema and add advanced layout data in your application code.
