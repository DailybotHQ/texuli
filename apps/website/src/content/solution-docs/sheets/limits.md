## Status

Sheets is **in development**. `@texuli/sheets` is on npm as `0.17.3`. Under 0.x a new minor may break. Native evaluation is planned, not built.

## Not built

- Collaboration on `@texuli/document/sync`
- Localized formula display
- Native (Kotlin) evaluation
- A hosted spreadsheet or storage service

Hard limits include 10,000-item ranges and 32,768-character strings. The formula language has no `INDIRECT`, `OFFSET`, `LAMBDA` or `RAND`.
