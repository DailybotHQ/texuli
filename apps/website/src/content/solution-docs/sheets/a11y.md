## Grid

The view is the data grid's APG grid with one tab stop, arrow-key navigation, Enter or F2 to edit, Escape to cancel, undo and redo, and TSV copy and paste. Columns are named by their letters. The first column holds row numbers. The formula bar is a named group. Formula errors are announced.

The cell editor is named by its column letter, for example `textbox` `B`. Host tests await it before typing.

## No HTML

Values paint as text. There is no `{@html}`, `innerHTML`, `eval` or `new Function`.
