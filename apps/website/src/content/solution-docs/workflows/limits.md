## Status

Workflows is **in development**. `@texuli/workflows` is on npm as `0.17.5`. Under 0.x a new minor may break. Native rendering is planned, not built.

## Not built

- A live automation or workflow runner
- Hosted persistence or multiplayer
- A visual schema builder outside the typed graph
- Native Compose, Android or iOS painting of the editor

Texuli draws and edits the graph. The host app stores it and owns any execution. Hard limits are 500 nodes and 2,000 edges.
