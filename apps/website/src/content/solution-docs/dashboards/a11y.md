## Keyboard and pointer

Dashboard move and resize handles are buttons. Space or Enter picks up a widget; arrow keys move or resize it by a grid step; Space or Enter drops it; Escape cancels and restores its prior layout. Tab cancels and moves focus onward. Left and right account for right-to-left direction.

The arrange toolbar also offers buttons for moving or sizing a selected widget, so a drag gesture is not required. Each step, refusal, drop, and cancellation is announced in a polite live region.

## Reading order and focus

Widgets render in grid reading order and their titles are headings. When widget content overflows and scrolls, its region becomes keyboard focusable and is named by the widget heading. Content that fits does not add a tab stop.

Use a meaningful label for the dashboard region. Give each chart or sparkline a text alternative, and make each metric value and comparison understandable without color or an arrow alone.

## Layout and motion

The component uses logical layout properties and keeps handles and focus visible in forced colors. Layout motion respects reduced-motion preferences; it does not animate on mount or hydration.
