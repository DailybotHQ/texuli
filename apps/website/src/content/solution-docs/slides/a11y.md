## Keyboard and input

Keys, a click on the slide, touch swipes and the toolbar run the same engine actions. Vertical stacks walk steps, then the stack, then the next slide. The overview is a thumbnail grid by keyboard or pointer. Focus after a keyboard move waits for the incoming slide.

## Motion and contrast

Transitions (`none`, `fade`, `fade-up`, `slide`, `zoom`, `morph`) cut or fade under `prefers-reduced-motion`. Background scrims keep text at least 4.5:1. Stage styles include reduced-motion and forced-colors rules.

The keyboard map, reflow at 320px and screen-reader notes live with the package stage docs and the recorded slides accessibility transcripts.
